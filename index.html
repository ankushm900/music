FAQ

Cassette Adda, Samjhaya Gaya

Cassette Adda kya hai?

Yeh ek free ambient radio website hai jo 90s ke Indian cassette-shop ka mahaul recreate karti hai — nostalgic gaane aur us daur ki vibe ke saath.

Kya yeh free hai?

Haan, Cassette Adda bilkul free hai, bina kisi sign-up ke, desktop aur mobile dono par chalta hai.

Gaane kahan se aate hain?

Yeh template khud ki audio file (jaise MP3) use karta hai, jise "songs" folder mein add kiya ja sakta hai — koi external streaming ki zaroorat nahi.

Kya main is design ko badal sakta hoon?

Bilkul — sabhi colors, fonts aur animations upar wale CSS variables (:root) se control hote hain, asaani se customize kiya ja sakta hai.
